# sysysali.github.io

This repository contains a small, modern Jekyll-based personal website for Syed Ali.

Quick notes
- The site is configured for GitHub Pages. Push this repo to a repository named `syysali.github.io` (same as your username) and Pages will serve the site from the `main` branch.
- Resume is included at `_Syed_Ali_Resume__SWE.pdf` and linked from the homepage.

Customize
- Edit `index.md` for hero text, contact details, interests, and project placeholders.
- Edit `projects.md` to add real project descriptions and links.
- Styles are in `assets/css/style.css`.

How to publish
1. Confirm the repo name is `syysali.github.io` and push to GitHub.
2. In the repository Settings -> Pages select the `main` branch (root) as the source if not automatically set.
3. Wait a minute; your site should be live at `https://syysali.github.io`.

If you want a different username/repo or a custom domain, update `_config.yml` accordingly.
